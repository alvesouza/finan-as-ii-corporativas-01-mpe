The Trade-off Dial

A firm promises to repay K next period. Every unit it promises is deductible while the firm is solvent, and pushes it closer to a default that costs C. Move the tax rate, the default cost and the spread of cash flows and watch the value-maximizing promise K* move: up with τ, down with C.

Ricca, Aula/Topic2B.pdf, slides 41–45 (static trade-off model); notes L03-04, eqs. (2)–(16). Uniform h on [X̲, X̄] and the default values are this page’s calibration (the slides give no numbers) — see the footer.

Tax and default friction

τ · tax rate

Paid on X − K only if the firm is solvent; the whole K is deductible. Higher τ makes each promised unit worth more.

C · fixed default cost

Deadweight cost paid out of X when X < K (lawyers, fire sales). Kept below X̲, as the slides assume.

Cash flow at t = 1, uniform

X̲ · lowest cash flow

Any promise up to X̲ is safe debt: value rises by τ/(1+rf) per unit.

X̄ · highest cash flow

Promising X̄ or more means default for sure: the whole tax bill is shielded but C is always paid.

Discounting and the inspected promise

rf · required return

Every investor is risk-neutral and discounts by 1+rf. It scales all values, never K*.

K · inspect a promise

The violet marker: read equity, debt and the slope of V at any repayment K, against the optimum.

Model, exactly as on slides 41–45: X has density h on [X̲, X̄]; the firm owes K at t = 1; if X ≥ K it pays tax τ(X − K), equity gets (1 − τ)(X − K) and debt gets K; if X < K no tax is paid, creditors get X − C. Investors are risk-neutral at rf. VU = (1 − τ)E[X]/(1+rf) (2); E(K) (4); D(K) (5); V(K) = E + D (6); marginal value (10); K* solves τ[1 − H(K*)] = C·h(K*) (11). Page calibration (declared; the slides give no numbers): h is uniform, so H(K) = (K − X̲)/(X̄ − X̲) and K* = X̄ − C/τ when C < τ(X̄ − X̲), otherwise the corner K* = X̲ (16); defaults X ~ U[50, 150], τ = 35%, C = 20, rf = 5%. All expressions are closed forms of the uniform case, no numerical root. Defaults reproduce note L03-04 §5: K* = 92.86, V(K*) = 81.63, VU = 61.90, PV shield 27.89, PV distress 8.16, default probability 42.9%, D = 71.53, E = 10.11. Landmarks, both exactly reachable: C = 0 gives K* = X̄ (shield the whole tax bill; any K ≥ X̄ ties); τ = 0 gives MM: any safe K ≤ X̲ is optimal and K* shows X̲, the top of that set. The interior/corner switch sits at C = τ(X̄ − X̲) = 35 at the defaults. Checked against an independent Python integration by companions/check_companions.py.
